# 2026-09-06 公共规则更新

本次从 fork 的 `f4d75f7`（2022-11-17）更新公共配置入口。旧 DivineEngine/Profiles 的远程资源存在失效地址，当前父仓库也没有可直接合入的较新规则版本，因此更新维护中的规则来源，并保留历史文件与作者致谢。

- 更新 Surge 的 Outbound/Inbound，新增 FilterOnly；新增 Clash/Mihomo 与 Shadowrocket 的对应模板，共九份。
- 使用 blackmatrix7/ios_rule_script 提交 `5f06cacdb752a951bba8511b25eadde77ebc683c`，14 类规则、3 个客户端、54 个实际文件。各文件更新时间不同，见锁文件。

- 公共出国模板提供 AI 与服务分类，回国模板默认直连并允许选择大陆出口；仅过滤模板不使用代理。
- 添加可重复生成、源文件哈希检查、分流回归验证及发布内容检查工具。
- 仓库仅保留公开数据与通用策略。节点、订阅、证书、设备路径和个性化例外由使用者在仓库外管理。

模板引用固定提交，避免上游变化在未经审查时直接改变使用者的分流。更新流程为 refresh → validate → 审查差异 → 发布；没有创建后台定时任务。

GMOogway/shadowrocket-rules 仍可作为补充规则来源参考，但未叠加到默认配置中。它主要提供 Shadowrocket 模块，模块规则优先于主配置；其全量广告过滤规模也较大，直接叠加会改变当前过滤和分流优先级。

本次校验覆盖公共模板的策略引用、组循环、最终策略、私网直连、域名分流、锁定资源哈希与域名拆分；另使用 Mihomo v1.19.30 对三份 YAML 执行 `-t`。这些是格式和规则检查，不包含真实节点连接、流媒体解锁或 Surge/Shadowrocket 客户端内的实际导入验证。
