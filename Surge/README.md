# Surge 公共配置

使用 [出国 Outbound.conf](Outbound.conf)、[回国 Inbound.conf](Inbound.conf) 或 [仅过滤 FilterOnly.conf](FilterOnly.conf)。模板不含节点，请在仓库外的本地副本中添加自己的代理。

最新规则来源、优先级、更新命令和兼容范围见 [仓库说明](../README.md)。原 `Ruleset`、模块及重写目录属于未更新的历史资源；新模板直接引用锁定版本的客户端专用上游规则。旧说明见 [历史记录](../docs/LEGACY-Surge-README.md)。

官方资源：[手册](https://manual.nssurge.com/) · [社区](https://community.nssurge.com/)
